# Unicode 编码转换工具设计

## 产品目标

新增一个 Unicode 编码转换工具，帮助开发者在普通字符和 JavaScript Unicode 转义格式之间快速互转。工具应保持现有编解码工具的轻量交互，不引入复杂配置或实时双向同步。

## 用户可见范围

- 工具名称：Unicode 编码转换
- 分类：编解码
- 输入：普通文本、Unicode 转义文本，或两者混合的文本
- 输出：转换后的文本结果
- 操作：编码、解码、复制、清除

## 编码能力

编码输出使用 JavaScript Unicode 转义格式：`\uXXXX`。

编码时提供两个可选策略：

1. 全部字符转义
   - 示例：`abc你好` → `\u0061\u0062\u0063\u4F60\u597D`
2. 仅非 ASCII 字符转义
   - 示例：`abc你好` → `abc\u4F60\u597D`

超出 BMP 的字符按 JavaScript 字符串转义习惯输出为 UTF-16 代理对。

## 解码能力

解码支持混合文本，只转换合法的 `\uXXXX` 片段，普通文本保持不变。

- 示例：`abc\u4F60\u597D` → `abc你好`
- 非法转义保持原样，不展示错误阻断流程
- 示例：`abc\uZZZZ` → `abc\uZZZZ`

## 页面体验

页面沿用现有编解码工具的简洁结构：

1. 顶部标题、图标和一句话说明
2. 使用提示，解释 `\uXXXX`、全部转义、仅非 ASCII 转义和非法转义保留策略
3. 输入文本框
4. 编码策略选择，仅影响编码操作
5. 编码、解码、清除按钮
6. 结果卡片，包含复制按钮

工具不做自动实时转换。用户输入内容后，通过按钮明确触发编码或解码，避免输入源和结果互相覆盖。

## 非目标

本次不支持以下能力：

- HTML 实体转换
- URL 编码、Base64 或其他编码格式
- `U+XXXX` 码点格式输出
- 文件上传或批量文件处理
- 自动检测输入类型并自动选择编码/解码

## 成功标准

- 用户能输入普通文本并输出 JavaScript Unicode 转义
- 用户能在“全部字符”和“仅非 ASCII”两种编码策略间切换
- 用户能输入混合文本并解码合法 `\uXXXX` 片段
- 非法转义不会报错或打断操作，而是保持原文
- 工具在首页和路由中作为“编解码”工具可访问
- 转换结果可复制，清除操作能重置输入和结果
